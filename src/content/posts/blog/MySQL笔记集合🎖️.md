# MySQL笔记集合

> 本篇是 MySQL 笔记的集合，也是导航哦喵🐱~

这四篇是按 **会写 → 用对 → 跑快 → 管好** 的顺序排的：先学语法把 SQL 写出来，再理顺表之间的关系和事务，然后深入索引、锁这些和性能相关的部分，最后是日志、主从复制、分库分表这些线上运维的事。建议按顺序看，也可以直接跳到当下需要的那篇。

> [!TIP] 赶时间的话，可以直接跳
> - 只想快速查语法 → **1. 基础语法篇**
> - 写业务时发现查询慢 → **3. 进阶篇**里的「索引」和「explain」两节
> - 要部署多台库、配主从、做读写分离 → **4. 运维篇**

## 1.MySQL基础-语法篇🐟️

**打地基的一篇。** 从 SQL 的通用语法和分类讲起，依次过一遍 DDL（建库建表）、DML（增删改）、DQL（查询）、DCL（权限），把"数据怎么存进去、怎么查出来"讲完整。

- **适合谁**：完全没写过 SQL，或者想系统地把语法过一遍
- **重点看**：DQL 查询那部分——`where` 条件、聚合、分组、排序、分页，这些是天天都要用的

[[MySQL基础-语法篇🐟️]]

## 2.MySQL基础-核心语法篇👻

**从"会写一句"进阶到"会设计一张表"。** 这篇讲函数、约束、多表查询和事务：主键外键怎么设、一对多/多对多怎么表达、多张表怎么连接起来查，以及事务的 ACID 和隔离级别。

- **适合谁**：单表 SQL 能写，但一遇到多表关联、或者"数据怎么不一致了"就发怵
- **重点看**：**多表查询**和**事务**——面试和实际开发的高频区

[[MySQL基础-核心语法篇👻]]

## 3.MySQL进阶篇📈

**搞明白"为什么慢"。** 从存储引擎（InnoDB / MyISAM / Memory 的差别与选型）讲到性能分析（慢查询日志、profile、explain 执行计划），再到索引原理（B+ 树、最左前缀、索引失效、覆盖索引）、SQL 优化，最后是视图、存储过程、触发器、锁和 MVCC。

- **适合谁**：能写业务 SQL，但查询一慢就不知道该从哪儿下手
- **重点看**：**索引**和 **explain**——这两块直接决定你排查性能问题的速度

[[MySQL进阶篇📈]]

## 4.MySQL运维篇☁️

**把数据库真正跑起来、管起来。** 讲了四类日志（错误日志、binlog、查询日志、慢查询日志）、主从复制的原理与搭建、分库分表（MyCat 的配置与九种分片规则）、读写分离（一主一从 / 双主双从），最后还有权限表和两个小技巧。

- **适合谁**：要自己部署和维护线上数据库，或者想弄懂"数据量大了到底怎么办"
- **重点看**：**主从复制的三步流程**和**分片规则怎么选**——这两点啃下来，整篇就不难了

[[MySQL运维篇☁️]]

# 尾声

四篇连起来，其实就一句话：**先把数据写对，再把表关系理顺，然后让查询跑得快，最后让库稳稳地活下去。**
